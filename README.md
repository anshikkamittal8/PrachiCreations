🌸 Prachi Creations - Luxe Gifting & Preservation
A premium full-stack e-commerce platform built for an art and gifting business. This application features dynamic category routing, a centralized product catalog powered by Supabase, and a custom inquiry system for bespoke orders.

✨ Core Features
Dynamic Collections: Real-time product fetching from Supabase based on category slugs (Photo Stonework, Resin Preservation, etc.).
Intelligent Pricing: Support for both fixed-price items and customizable "Price on Request" products for bespoke hampers.
RLS Protected Backend: Implements Supabase Row Level Security to ensure customer inquiries are private while keeping the catalog public.
Direct Order Flow: Deep-linked integration with WhatsApp and Instagram for seamless customer conversion.
Responsive UI: A minimalist and colorful aesthetic optimized for both desktop and mobile browsing.

🚀 Tech Stack
Frontend: React.js with Tailwind CSS.
Routing: React Router DOM for dynamic product and category paths.
Backend/Database: Supabase (PostgreSQL).
Language: JavaScript / TypeScript.
